
\chapter{Introducción}
\textbf{Notas}:\medskip


“El modelo SLV requiere como input de mercado la superficie de volatilidad implícita de opciones vanilla,
además de spot, tipos y dividendos/forwards. Sobre esa información se calibra un modelo de volatilidad
estocástica base (Heston), y se determina el componente local o leverage function que garantiza el
ajuste a la superficie observada.”
